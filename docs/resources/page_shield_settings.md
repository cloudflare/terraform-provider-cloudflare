# cloudflare_page_shield_settings (Resource)

Accepted Permissions

- `Domain Page Shield`
- `Domain Page Shield Read`
- `Page Shield`
- `Page Shield Read`
- `Zone Settings Read`
- `Zone Settings Write`

## Example Usage

```terraform
resource "cloudflare_page_shield_settings" "example_page_shield_settings" {
  zone_id                           = "023e105f4ecef8ad9ca31a8372d0c353"
  enabled                           = true
  use_cloudflare_reporting_endpoint = true
  use_connection_url_path           = false
}
```

## Schema

### Required

- `zone_id` (String) Identifier.

### Optional

- `enabled` (Boolean) When true, indicates that Page Shield is enabled. Page Shield must be enabled for continuous script monitoring, malicious script detection, and code change detection to work.
- `use_cloudflare_reporting_endpoint` (Boolean) When true, CSP reports will be sent to the Cloudflare-managed reporting endpoint (https://csp-reporting.cloudflare.com/cdn-cgi/script_monitor/report) so detected resources appear in the Page Shield dashboard.
- `use_connection_url_path` (Boolean) When true, the paths associated with connection URLs will also be analyzed.

### Read-Only

- `id` (String) Identifier.
- `updated_at` (String) The timestamp of when the setting was last updated.
