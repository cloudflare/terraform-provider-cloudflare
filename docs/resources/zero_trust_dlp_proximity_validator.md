# cloudflare_zero_trust_dlp_proximity_validator (Resource)

Accepted Permissions

- `Zero Trust Read`
- `Zero Trust Write`

## Example Usage

```terraform
resource "cloudflare_zero_trust_dlp_proximity_validator" "example_zero_trust_dlp_proximity_validator" {
  account_id = "account_id"
  name = "HIPAA context words"
  words = [{
    weight = "strong"
    word = "social security number"
  }]
```

## Schema

### Required

- `account_id` (String)
- `name` (String) A name for this validator, at most 50 characters.
- `words` (Attributes Set) The words that raise confidence when found near a match, at most 100 per validator. Matching
ignores case, so the list may not contain the same word twice with different capitalisation.
Words are stored as sent.

For example, a validator for medical record numbers might use
`[{"word": "patient", "weight": "strong"}, {"word": "diagnosis", "weight": "moderate"},
{"word": "mrn", "weight": "weak"}]`. (see [below for nested schema](#nestedatt--words))
