## Example Usage

  account_id = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

### Required

- `account_id` (String) Cloudflare account ID (32-character hexadecimal string)
- `basic_auth_credential_ids` (Set of String) IDs of basic-auth credentials to attach
- `default_mode` (String) Default traffic mode: ALLOW or BLOCK
Available values: "ALLOW", "BLOCK".

- `policy_set_ids` (Set of String) IDs of policy sets to attach

- `domain_acl_id` (String) ID of the domain ACL to attach (omit or null for none)
- `on_error_action` (String) Action for runtime Rego errors. Omit to use BLOCK.
Available values: "BLOCK", "SKIP".
- `rego_raise_error` (Boolean) Whether OPA builtin failures are raised as runtime evaluation errors. Omit to use the default true value.
