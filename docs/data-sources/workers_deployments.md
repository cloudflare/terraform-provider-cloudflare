# cloudflare_workers_deployments (Data Source)

Accepted Permissions

- `Individual Workers Admin`
- `Individual Workers Content Read-Only`
- `Individual Workers Editor`
- `Individual Workers Metadata Read-Only`
- `Workers Admin`
- `Workers Content Read-Only`
- `Workers Editor`
- `Workers Metadata Read-Only`
- `Workers Scripts Read`

## Example Usage

```terraform
data "cloudflare_workers_deployments" "example_workers_deployments" {
  account_id = "023e105f4ecef8ad9ca31a8372d0c353"
  script_name = "this-is_my_script-01"
  since = "2019-12-27T18:11:19.117Z"
  until = "2019-12-27T18:11:19.117Z"
}
```
