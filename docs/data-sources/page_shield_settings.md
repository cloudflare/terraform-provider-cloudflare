### Read-Only

- `enabled` (Boolean) When true, indicates that Page Shield is enabled. Page Shield must be enabled for continuous script monitoring, malicious script detection, and code change detection to work.
- `id` (String) Identifier.
- `updated_at` (String) The timestamp of when the setting was last updated.
